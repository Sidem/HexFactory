# Visual comparison captures

Renderer comparison screenshots are recorded at the four viewports the v0.25 Three.js cutover was
qualified against. The `v0.24-*` images preserve the hybrid WebGL2/Canvas starting point; the
`v0.25-*` images are the final cutover evidence.

The opening and Factory demo each have 1440×900 desktop, 1366×768 laptop-size, 720×900 narrow, and
390×844 mobile captures. `v0.25-hover-alignment-1440x900.png` records the corrected pointy-top hover
ring on the same exact-radius terrain lattice. `v0.25-contact-1440x900.png` is the full generated
machine contact sheet: 23 definitions, three ladder states, four statuses, six orbits, one retained
WebGL context.

HexFactory browser capacity ladder

The same deterministic ladder npm run bench runs natively, measured here as wasm inside a module worker, plus the costs a native run cannot see: the worker RPC round trip, the main-thread delta merge, and the two canvases the game draws (1440×900 world, 178 px minimap). Build the harness artifact with npm run build:wasm:bench first. Record results in docs/BENCHMARKS.md.
